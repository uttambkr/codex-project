# ChatWave

ChatWave is a lightweight WhatsApp-like real-time chat application with a familiar split-pane interface and instant updates.

## Features

- Real-time room messaging
- Join with a display name
- Presence panel for online users
- Typing indicator
- Responsive WhatsApp-inspired UI
- Zero third-party runtime dependencies

## Run locally

```bash
npm start
```

Then open http://localhost:3000 in your browser.
